# benPilot

**benPilot is a recovery fork of [jvePilot](https://github.com/j-vanetten/openpilot), originally authored by John Van Etten ([j-vanetten](https://github.com/j-vanetten)), and built on [comma.ai openpilot](https://github.com/commaai/openpilot).**

The originating release is jvePilot **0.9.8(v3.18)**, July 20, 2025, commit [`b47add65d32e232b939d4915cca0b5a9ddafc48d`](https://github.com/j-vanetten/openpilot/commit/b47add65d32e232b939d4915cca0b5a9ddafc48d). Original attribution, license files and source history are preserved.

The `jvePilot-release` branch retains that exact original source. benPilot currently adds recovery/build evidence and a pinned installer candidate; full native model compilation, device validation and verified backup/rollback remain pending. The original on-device jvePilot version and settings names are retained for this recovery stage.

- [benPilot installer candidate](https://github.com/benbernard/benPilot/releases/tag/benpilot-july-c3-candidate-2) — preparation only; do not load before the required backup and compatibility review.
- [Recovered original source](https://github.com/benbernard/benPilot/releases/tag/jve-july-2025-recovery-source-1).
- [Source/build investigation](https://github.com/benbernard/benPilot/pull/1) and [installer preparation](https://github.com/benbernard/benPilot/pull/2).
